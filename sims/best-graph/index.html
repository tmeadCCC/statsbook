      What you should notice

      Start by asking what kind of data you have. Qualitative (categorical) data go in a bar graph, pie chart or Pareto chart; when the categories have an order (ordinal data), use a bar graph with the bars in that order. Qualitative data split into groups are best compared with a split (side-by-side) bar graph. Quantitative data go in a histogram, dot plot, stem-and-leaf plot or boxplot, which show the shape, center and spread. Data measured over time go in a time-series plot.
